# 测试用例与实测结果

本文件记录智能共享自习室管理系统（项目编号 26）的验收测试用例、输入与期望输出，以及 2026-11-20 在本机的实测结果。
所有用例由 `scripts/e2e.ps1` 通过 HTTP 接口自动执行，原始日志见 `scripts/_e2e.log`，本次运行结果：**SUMMARY pass=64 fail=0**。

## 0. 复现方式

```powershell
# 1) 重置数据库到初始数据（1 间自习室、10 个座位、7 个账号、单价 4.00）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\reset_db.ps1

# 2) 启动后端（另开一个终端，FG_ENDPOINT 指向本地云函数模拟器或华为云函数地址）
java -jar backend\target\studyroom-backend-1.0.0.jar

# 3) 跑用例（脚本自己会先把模拟时钟归零）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\e2e.ps1
```

实测环境：Windows 11、JDK 21.0.12.1、Spring Boot 3.3.5、MySQL 9.5.0（库 `reading_room`）、Node 24.22.3、Vue 3.5 + Vite 5.4、华为云 FunctionGraph（本地模拟器 `scripts/mock_fg.py`，与云端同一份 `billing.py`）。
