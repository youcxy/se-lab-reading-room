## 二、录制工具与参数（任选其一）

**推荐 OBS Studio（免费，能同时录浏览器 / 控制台 / 文件管理器）**

1. 官网下载安装 → 「设置 → 视频」：基础分辨率 `1920x1080`、输出分辨率 `1920x1080`、帧率 `30 FPS`。
2. 「来源」→ `+` → **显示器采集**（或窗口采集，只录浏览器）；需要口播就再确认「音频」里麦克风已启用。
3. 点「开始录制」，录完点「停止录制」，MP4 默认保存在「视频」文件夹。

**不想装软件**：Windows 11 自带「截图工具」→ `Win + Shift + S` → 切到「**录制**」→ 框选浏览器窗口 → 开始 / 停止，自动存成 mp4。`Win + G`（Xbox Game Bar）也能录，但只能录单个应用窗口，切到华为云控制台时会断，不推荐做全流程。

**浏览器准备**：F11 全屏、缩放 100%、关掉无关标签页与书签栏（`Ctrl+Shift+B`）、关闭系统通知/弹窗、提前登录 `s001`。浏览器地址用公网 IP，**不要用 127.0.0.1**（那样录到的是本机，不是云上部署）。

## 六、讲的时候要点到的三个易错点

## 八、如实说明（重要，别在视频里说错）

需求第三节第 6 条原文是「按小时计费的金额**由华为云函数工作流计算，页面显示云端结果**」。这一项现在有两条路径，**录视频前必须先确认走的是哪条**：

| 当前通路（看板绿色/橙色标签） | `source: CLOUD` 的真实含义 | 视频里该怎么说 |
| --- | --- | --- |
| `FUNCTIONGRAPH_AKSK`（绿色） | **真·云端**：后端用 AK/SK 签名直调 FunctionGraph 同步执行 API，页面金额是华为云函数返回值 | 可以说「金额由华为云函数工作流计算，页面显示云端结果」 |
| `HTTP_ENDPOINT`（橙色） | **本地模拟器**：ECS 上的 `mock_fg.py` 按云端同款 handler 返回，不是华为云真算的 | 只能说「本地模拟云端接口」，并补录控制台测试片段；**不要**说成华为云真算 |

**代码已按免费路径改造完成**（见 `docs/GitHub与华为云配置步骤.md` 第八章）：后端用官方 SDK 走 AK/SK 直调 `POST /v2/{project_id}/fgs/functions/{urn}/invocations`，不买 APIG、不产生额外账单，对应六.2「接口形式自定，访问密钥不得写入仓库」。密钥只放 ECS 的 `/etc/studyroom/cloud.env`（权限 600）。**还差你在 IAM 建一次访问密钥并填入该文件**，填完重启后 `/api/cloud/status` 就会变成 `FUNCTIONGRAPH_AKSK`。

其他如实说明：

- 云端调用失败时后端**只回退 `LOCAL`**，不会悄悄退回模拟器冒充 `CLOUD`；`detail` 会写明错误码，方便排查。
- `detail` 里的「与本地核算一致」是后端的一致性校验；不一致会明确提示，避免把错误金额当成云端结果。
- 定时释放函数那半边**已经达标**：云端函数真实运行、每日定时触发器、回调 ECS 成功、重复触发幂等（需求原文允许「演示时可手工触发同一函数」）。

## 九、常见问题

| 现象 | 处理 |
| --- | --- |
| 页面打不开 / 连接超时 | 先看 ECS 是否被「定时删除」自动删掉了；再确认安全组入方向放行 80 |
| 页面金额来源变 `LOCAL` | 先看 `/api/cloud/status`：若为 `HTTP_ENDPOINT`，是模拟器挂了（`systemctl restart studyroom-mockfg`）；若为 `FUNCTIONGRAPH_AKSK`，看 `detail` 里的 HTTP 错误码（401=AK/SK 错，403=项目ID/区域不符，404=URN 错），详见配置文档第八章排错表 |
| 卡片标签是橙色 `HTTP_ENDPOINT` | AK/SK 四项没填全或没重启：`sudo vi /etc/studyroom/cloud.env` → `sudo systemctl restart studyroom` |
| 数据脏了（座位全占用） | 执行第三节第 2 步的 `mysql -u root < /opt/studyroom/sql/init.sql` 重置 |
| 云端「测试」返回 500 / 502 | `BACKEND_BASE` 应为 `http://120.46.192.201`（不带端口、不带结尾斜杠）；或 ECS 已被删除 |
| 云端测试 `triggeredAt: "None"` | 正常，测试事件 `{}` 没带 `time`；想有值就填 `{"time":"2026-11-28T00:05:00Z"}` |
| 找不到「手工触发一次」 | 直接开 `http://120.46.192.201/#/dashboard`，`Ctrl+F` 搜「云函数」，第二张卡片右半边橙色按钮 |

## 十、录完之后：立刻删除 ECS（别只关机）

按需实例**关机后云硬盘与 EIP 仍计费**。ECS 列表 →「更多 → 删除」→ 勾选同步释放系统盘 + 弹性公网 IP → 输入 `DELETE` 确认；再查账单、资源列表、代金券余额，把「0 自费」截图放进报告。删机后 `seat-scan-func` 的 `BACKEND_BASE` 会失效（测试变 502），但定时触发器配置仍在且不产生费用，视频录完可停用触发器避免每天失败日志。

**删机前先清密钥**（若填过 AK/SK）：`sudo shred -u /etc/studyroom/cloud.env`，再到 IAM → 访问密钥 → 删除本次创建的密钥。密钥只存在 ECS 本机，仓库里只有空模板 `deploy/cloud.env.example`。
