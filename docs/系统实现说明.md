# 智能共享自习室管理系统（项目编号 26）

软件工程实验课程小组项目。4 人小组，5 周周期，Web 应用。
需求来源：《26-智能共享自习室管理系统-需求文档》，开发依据见 `docs/` 下的《项目开发计划》与《小组实验流程与分工手册》。

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Java 21 + Spring Boot 3.3.5 + spring-boot-starter-jdbc（JdbcTemplate）+ Maven |
| 数据库 | MySQL 9.5（本机服务名 MySQL95，库 `reading_room`，utf8mb4） |
| 前端 | Node 24 + Vite 5 + Vue 3.5 + Vue Router 4 + Element Plus + axios |
| 云端 | 华为云 FunctionGraph：HTTP 触发器计费函数 + 每日定时触发器释放超时座位 |

计费与业务规则全部落在后端与云函数一侧，页面只做展示与操作，金额统一保留两位小数（HALF_UP）。

- 初始化规格：1 间自习室、10 个座位（A01–A10）、单价 4.00 元/小时、7 个账号（含月卡用户与当日包天卡用户）
- 连接信息写入本地 `.env`（参照 `.env.example`），**密码不提交仓库**
- 设计说明见 `docs/数据库设计说明.md`，ER 图见 `docs/ER图.png`

DBeaver 连接注意：MySQL 9.5 账号插件是 `caching_sha2_password`，驱动属性里要设 `allowPublicKeyRetrieval=true`（或用 URL 参数 `?allowPublicKeyRetrieval=true&useSSL=false`）。

## 启动命令

### 1. 初始化数据库

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\reset_db.ps1
```

等价于依次执行 `sql\init.sql`、`sql\init.sql`，并把模拟时钟归零。若还想载入一天的演示数据，再执行 `sql\test_data.sql`。

### 2. 启动后端（端口 8080）

```powershell
cd backend
mvn -B -DskipTests package
java -jar target\studyroom-backend-1.0.0.jar
```

说明：本机项目路径含中文，`mvn spring-boot:run` 会因 fork 出的 JVM 类路径乱码报 `ClassNotFoundException`，所以统一用 `package` + `java -jar`。

可选环境变量：

| 变量 | 作用 |
|---|---|
| `FG_ENDPOINT` | 云函数 HTTP 触发器地址；为空时按本地算法计算并把来源标为 `LOCAL`，指向函数（或本地模拟器）时来源标为 `CLOUD` |
| `STUDY_DB_USER` / `STUDY_DB_PASSWORD` | 覆盖默认数据库账号（默认 `study` / `Study@123456`） |

### 3. 启动前端（端口 5173）

```powershell
cd src\frontend
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173/`，`/api` 已由 Vite 代理到 `http://127.0.0.1:8080`。生产构建：`npm run build`（产物在 `dist/`）。

### 4. 云函数本地模拟（演示云端计费用，可选）

```powershell
python scripts\mock_fg.py
# 然后在启动后端前设置：set FG_ENDPOINT=http://127.0.0.1:9100/billing
```

模拟器直接 import `cloud/functiongraph/billing/billing.py` 与 `timeout_release/timeout_release.py`，与云端是同一份代码。

## 主要接口

| 方法与路径 | 说明 |
|---|---|
| `GET /api/health` | 健康检查，返回业务时间 |
| `POST /api/auth/login` | 登录（`login`、`password`） |
| `GET /api/users` | 用户列表（页面用于切换账号） |
| `GET/PUT /api/clock`、`POST /api/clock/reset` | 模拟当前时间：`advanceMinutes` 前进、`offsetSeconds` 设置偏移、reset 归零 |
| `GET /api/room`、`GET /api/seats` | 自习室与座位状态 |
| `POST /api/seats/{seatId}/reserve` | 预约（body：`userId`） |
| `GET /api/reservations`、`GET /api/reservations/{id}` | 预约列表与详情 |
| `POST /api/reservations/{id}/checkin` · `leave` · `end-leave` · `checkout` | 签到、暂离、结束暂离、签退（body：`userId`） |
| `POST /api/timeout/run` | 手工触发“释放超时座位”，与定时触发器同一逻辑，可重复触发不二次扣费 |
| `POST /api/cloud/quote` | 调用云函数计算金额（`unitPrice`、`minutes`） |
| `GET /api/bills?userId=` | 费用明细 |
| `GET/POST /api/complaints`、`POST /api/complaints/{id}/handle` | 投诉提交与处理（处理结果为空则拒绝置为已处理） |
| `GET /api/dashboard`、`GET /api/dashboard/orders` | 看板汇总与订单明细（订单数、营收、客单价、复购人数、上座率、待处理投诉） |
| `GET /api/pricing/status`、`POST /api/pricing/adjust`、`GET /api/pricing/changes`、`GET /api/pricing/changes/export` | 上座率与调价、变价记录、CSV 导出（仅店长可调价） |
